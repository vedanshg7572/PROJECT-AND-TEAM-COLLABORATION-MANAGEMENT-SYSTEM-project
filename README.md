# 📋 Project & Team Collaboration Management System

A simple, beautiful **Project and Task Management** web application built with pure HTML, CSS, and JavaScript — no backend or server required!

## 🚀 Features

- 📊 **Dashboard** — Overview of all projects, tasks, completed & pending counts
- 📁 **Project Management** — Create and delete projects with name, description & deadline
- ✅ **Task Management** — Add tasks with title, description, priority, deadline & assignee
- 🎯 **Priority Levels** — High / Medium / Low with color-coded badges
- 📈 **Progress Tracking** — Auto-calculated progress bar per project
- 🔄 **Status Updates** — To Do → In Progress → Done
- 🔍 **Filters & Search** — Filter tasks by status, priority; search by name
- 💾 **LocalStorage** — All data is saved in the browser (no database needed)
- 🌙 **Dark Theme** — Clean modern dark UI

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Structure |
